# Dungeon tileset restyle

Mode: built-in image generation, editing the existing tileset as the layout reference. The goal is realistic weathered materials with the project's warm charcoal, umber, brown, cream, and brick-red palette.

Runtime destination: `assets/images/tiled/tile_set.png`. The runtime atlas is 448 × 448 with 49 source tiles of 64 × 64 pixels. `tileSet.json` and `map.json` both use 64-pixel tiles. Pixel-space collision and map-object coordinates are scaled fourfold from the original 16-pixel data; tile IDs and tile-layer ordering remain unchanged.

Original artwork: [art/dungeon/tile_set-original.png](art/dungeon/tile_set-original.png).

Selected high-resolution source: [art/dungeon/tile_set-realistic-source.png](art/dungeon/tile_set-realistic-source.png). The runtime PNG is resampled directly from this 1254 × 1254 source to 448 × 448, preserving more material detail than the earlier 112-pixel export. The supplied download is the same generated artwork. The earlier low-resolution export is retained at [art/dungeon/tile_set-16px.png](art/dungeon/tile_set-16px.png).

Assembled map preview: [art/dungeon/dungeon-map-preview.png](art/dungeon/dungeon-map-preview.png). This renders the existing tile layers at the game's 32-pixel tile scale, without actors or dynamic lighting. The map and collision coordinates are migrated to the new source resolution while retaining their original world-space layout; the generated artwork is a material restyle rather than a pixel-identical tracing of the old silhouettes.

## HD metadata migration

Both the map grid and source tiles are 64 pixels. All 44 map objects and 20 collision rectangles have four times their former pixel coordinates and sizes. The unchanged `forceTileSize: Vector2(tileSize, tileSize)` in `lib/game.dart` renders each source tile at 32 world pixels, retaining room dimensions, player scale, and object placement. Map width and height remain 50 tiles each.

`test/dungeon_tileset_test.dart` checks the image dimensions, source tile contract, unchanged layer GIDs, and every object's and collision rectangle's world coordinates against a pre-migration fixture. The image generation prompts below record the earlier artwork creation; their 112-pixel layout references describe that source design rather than the current runtime resolution.
